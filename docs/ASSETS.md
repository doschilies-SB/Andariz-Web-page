# Procedencia de los recursos

## Recursos definitivos recibidos

- Logo, isotipo, aves, huella, rostros, río, conexión y papel: extraídos/normalizados desde `Archivo(1).zip` de la marca. Los SVG conservan los trazos originales y un viewBox para el motivo utilizado.
- `emi-amazonas.webp` y `emi-portrait.webp`: imágenes incorporadas en `ARCHIVO 2 SVG_ANDARIZ-03.svg`, extraídas en la etapa anterior. La primera se usa en la historia de Emi.
- Bordes rasgados: SVG de apoyo construidos para la interfaz; no son fotografías ni originales del manual.

## Referencia provisional de la home

`assets/reference/boceto.png` corresponde a “Andariz travel magazine in vivid spreads(1).png”, el diseño aprobado. Se utiliza como referencia completa y como fuente provisional de las cinco escenas, el sello y el matasellos mediante ventanas CSS. La fotografía del hero incluye la palma, cinta y etiqueta del boceto.

Estos fragmentos no deben identificarse como originales fotográficos de alta resolución. Ver `RECURSOS_PENDIENTES.md` para sustituirlos. No se generaron nuevas fotografías en esta reconstrucción.

## Tipografías

- **Calistoga** para titulares; SIL Open Font License incluida.
- **Caveat** para manuscritas; SIL Open Font License incluida.
- **Courier New / Courier / monospace** para cuerpo y etiquetas, usando la fuente disponible en el sistema del visitante.
- Fraunces se conserva de la primera entrega pero ya no se usa en los titulares.
- Reislust y Ranberg Rounded Rough Demo, recibidas en el ZIP, se conservan en `docs/originales-tipografias/`. No son las letras dibujadas por el PNG. La demo solo tiene A–Z y a–z, sin tildes, puntuación ni cifras. No se presentan como una licencia de uso web comercial ni se cargan automáticamente.
